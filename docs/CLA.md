## How to sign

You do not need to send this file anywhere. When you open your first pull
request against the Project, an automated check will post a comment asking you
to confirm. Reply on that pull request with exactly:

```
I have read the CLA Document and I hereby sign the CLA
```

Your GitHub username, the date, and the pull request are recorded in
`signatures/cla.json` on the `cla-signatures` branch. You only need to sign
once; subsequent pull requests are checked against that record automatically.
